PANTRY PAL - WINDOWS PORTABLE RELEASE

System requirements
-------------------
- 64-bit Windows 10 or Windows 11
- No Qt installation is required
- No administrator access is required

How to run
----------
1. Extract the entire PantryPal-Windows folder from the ZIP file.
2. Keep PantryPal.exe, the DLL files, and the plugin folders together.
3. Double-click PantryPal.exe.

Default login
-------------
Username: 123
Password: 123

Windows SmartScreen
-------------------
This classroom build is not code-signed. If Windows SmartScreen appears,
choose "More info" and then "Run anyway" after confirming that this ZIP came
from your trusted project source.

Data storage
------------
Pantry Pal creates its SQLite database in the signed-in Windows user's AppData
folder. Each Windows user therefore receives a separate pantry database, and
the program folder remains portable.

Troubleshooting
---------------
- Do not copy or run PantryPal.exe by itself. It needs the included DLL files
  and plugin folders.
- If the ZIP was downloaded from the internet, extract it before running the
  program instead of opening the EXE from inside the ZIP preview.
