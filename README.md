# Pantry-Pal
A desktop application that is designed to help households manage their food efficiently.

## Features

- Household inventory
- Food categories
- Storage locations
- Expiration tracking
- Expiration alerts
- Search \ Filter
- Grocery lists

## Tech Stack

| Component | Technology | Reason |
|-----------|------------|--------|
| Language | C++20 | Modern language features and good library support. |
| GUI Framework | Qt 6 | The industry standard for cross-platform desktop applications. |
| IDE | Qt Creator or Visual Studio 2022 | Excellent integration with Qt. |
| Database | SQLite | Lightweight, embedded, and perfect for desktop applications. |
| Database Library | Qt SQL (QSqlDatabase) | Built into Qt, making SQLite integration straightforward. |
| Build System | CMake | Industry standard for C++ projects. |
| Version Control | Git + GitHub | Collaboration and version tracking. |
| Testing | GoogleTest | Widely used C++ testing framework. |
| Charts | Qt Charts | Integrates seamlessly with Qt for statistics dashboards. |
